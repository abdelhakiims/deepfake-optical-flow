# Face detection model

Download `face_detection_yunet_2023mar.onnx` from the OpenCV Zoo
(https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet) and put it
in this folder, or give its path with `--face_model` or the `DEEPFAKE_FACE_MODEL`
environment variable. The file is about 230 KB; a much smaller file is a saved web
page, not the model.

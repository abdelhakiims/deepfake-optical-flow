# Official FaceForensics++ split

`train.json`, `val.json` and `test.json` are the official split of FaceForensics++
(360 / 70 / 70 pairs of source videos), copied from the FaceForensics repository
(https://github.com/ondyari/FaceForensics, folder `dataset/splits`). The fakes of
pair `[a, b]` are `a_b` and `b_a`.
